# 公众号发布助手 / WeChat Official Account Publisher

`wechat-official-account-publisher` · v0.1.0 · [GitHub Releases](https://github.com/simple0926/wechat-official-account-publisher/releases) · [发行说明 / Release notes](RELEASE_NOTES.md)

## 中文

把真实素材做成经作者确认的公众号文章和可复制的富文本发布包。

覆盖采访、方向与系列确认、正文、配图、复制版和发布前检查。安装后可先填随包账号模板，并按需接入作者有权使用的素材。

1. 从 [GitHub Releases](https://github.com/simple0926/wechat-official-account-publisher/releases/tag/v0.1.0) 的附件下载 `wechat-official-account-publisher-v0.1.0.zip`。
2. 解压后把 `wechat-official-account-publisher/` 文件夹复制到 `~/.codex/skills/`。更新前先备份你自行改过的文件。
3. 在 Codex 里输入 `$wechat-official-account-publisher`，附上你的目标、已有材料和交付要求。

构建与审计依赖 Python 3，Markdown 转换可使用 Pandoc。公众号编辑器粘贴、手机预览和实际发布，需要使用目标账号逐篇确认。

## English

Turns source material into an author-approved WeChat article and a copy-ready rich-text package.

Covers interviews, direction and series approval, writing, illustrations, the copy-ready edition, and preflight review. Start with the included account template and supply any assets you are authorized to use.

1. Download the attached `wechat-official-account-publisher-v0.1.0.zip` from [GitHub Releases](https://github.com/simple0926/wechat-official-account-publisher/releases/tag/v0.1.0).
2. Extract and copy the `wechat-official-account-publisher/` folder to `~/.codex/skills/`. Back up any local customizations before updating.
3. In Codex, invoke `$wechat-official-account-publisher` with your goal, available inputs, and expected deliverables.

Build and audit use Python 3, with Pandoc available for Markdown conversion. Editor paste, mobile preview, and actual publishing require confirmation in the target account for each article.
