# 公众号发布助手 / WeChat Official Account Publisher v0.1.0

## 中文

首个公开版包含通用账号和反馈模板、独立标题与正文复制、外部网页链接的纯文本处理、手动复制降级及静态审计。

构建与审计依赖 Python 3，Markdown 转换可使用 Pandoc。公众号编辑器粘贴、手机预览和实际发布，需要使用目标账号逐篇确认。

请选择 Release 附件里的 `wechat-official-account-publisher-v0.1.0.zip` 安装。

## English

Initial public release includes generic account and feedback templates, separate title and body copying, plain-text handling for external links, a manual copy fallback, and static auditing.

Build and audit use Python 3, with Pandoc available for Markdown conversion. Editor paste, mobile preview, and actual publishing require confirmation in the target account for each article.

Install using the attached `wechat-official-account-publisher-v0.1.0.zip` from the release.
